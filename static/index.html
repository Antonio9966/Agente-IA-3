🚀 Guía de Despliegue en Git y Render

Pasos listos para subir este proyecto a GitHub y publicarlo en producción en Render.

1. Subir a tu repositorio de GitHub

git init
git add .
git commit -m "feat: extractor cientifico de literatura y matrices"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/TU_REPOSITORIO.git
git push -u origin main

2. Desplegar en Render (Web Service)

  1. Crea una cuenta o inicia sesión en render.com.
  2. Haz clic en New + y selecciona Web Service.
  3. Conecta tu repositorio de GitHub recién creado.
  4. Configura los campos:
    • Runtime: Python 3
    • Build Command: pip install -r requirements.txt
    • Start Command: uvicorn main:app --host 0.0.0.0 --port $PORT
  5. En la sección Environment Variables, añade:
    • Key: GROQ_API_KEY
    • Value: Tu clave de Groq (gsk_...)
  6. Haz clic en Create Web Service. ¡En 2 minutos tu aplicativo estará en vivo en tu URL .onrender.com!
